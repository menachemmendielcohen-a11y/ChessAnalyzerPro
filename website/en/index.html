How does it work?

Two parts work together: a small browser extension and a desktop analysis program.

⬇️

Download the game

The Chrome extension adds a button to the Chess.com game page and saves any finished game as a PGN file.

📂

Open it in the program

Click "Choose a game from your computer", pick the PGN file, and the game appears on an interactive board.

🔍

Get a full analysis

The chess engine checks every move, marks mistakes and missed chances, and shows what would have been better.

Key features

Everything you need from a chess game analysis tool to see where you played well, where you went wrong and how to improve.

🏷️

A quality label for every move

Brilliant, Great, Best, Good, Inaccuracy, Mistake, Blunder and Miss – with an icon and colour, next to the move and on the board.

🎯

Top three engine moves

Three arrows on the board in every position: green for the best move, blue for the second and orange for the third.

📊

Evaluation bar

A vertical bar beside the board shows who is ahead, with the engine's numeric evaluation updated on every move.

💯

Accuracy and game summary

An accuracy percentage for each player and a count of brilliant moves, great moves, mistakes and blunders.

💡

Explanations and better moves

Every move comes with a short reason for its label and, after a mistake, the move that would have been better.

🔌

Stockfish built in, fully offline

A free chess engine that installs together with the program and starts automatically in the background. All analysis stays on your PC.

What does each mark mean?

Each move is classified by how much it changed the winning chances calculated by the engine.

  • !!BrilliantAn exceptional move, usually a piece sacrifice the engine approves.
  • !Great moveThe only move that holds the position or keeps the advantage.
  • ★Best moveExactly what the engine recommends.
  • ✓Good moveA sound move, even if not the most precise.
  • ?!InaccuracyA slightly weaker move.
  • ?MistakeA move that hurts the player's position.
  • ??BlunderA move that seriously damages the position.
  • ✕MissA missed chance after the opponent's error.

A Stockfish chess analyzer – not the official Stockfish website

Looking for a free chess engine download? Chess Analyzer Pro is chess analysis software that ships with Stockfish, one of the strongest chess engines in the world. One installer sets up both the PGN analyzer and the engine, so there is no separate engine download and nothing to configure.

To be clear: this is not the official Stockfish website, and the project is not affiliated with the Stockfish developers or with Chess.com. Stockfish is developed by the Stockfish community and distributed under the GPLv3; its official site is stockfishchess.org.

Chess Analyzer Pro itself is free, open-source software released under the GNU GPL version 3.

Fair play: analysis is for finished games only. The extension will not download a game that is still in progress, and the program will not analyse an unfinished game.

Frequently asked questions

Is Chess Analyzer Pro really free?

Yes. The program and the extension are completely free, with no subscription and no limit on the number of games. It is open-source software under the GPLv3.

Do I need to download Stockfish separately?

No. The Stockfish chess engine is included in the installer and starts automatically in the background when you pick a game.

Do I need an internet connection to analyse?

No. All analysis runs on your computer. You only need the internet to download the game from Chess.com.

Which files can it open?

PGN files – the standard format for chess games. PGN files from other sources work too, not only Chess.com.

Can I use it during a game?

No. The program is for learning from finished games. Using an engine during a live game is cheating and against Chess.com rules.

Which systems are supported?

Windows 10 and Windows 11, 64-bit. The extension works in Chrome and Chromium-based browsers.
