Installation and user guide

Six simple steps from installing to analysing your first game. No technical knowledge needed.

  1. Install the Chrome extension

    Click "Install the Chrome extension". On the Chrome Web Store page that opens, click "Add to Chrome" and confirm. That is it – the extension is installed. Until the extension is approved in the store you can install it manually: download the extension ZIP, extract it to a folder, open chrome://extensions, turn on "Developer mode", click "Load unpacked" and pick the extracted folder.

    🧩 Install the Chrome extensionThe extension is awaiting approval in the Chrome Web Store. The link will appear here as soon as it is published.📦 Meanwhile: download the extension as a ZIP for manual installation

  2. Download the Windows program

    Click "Download Chess Analyzer Pro for Windows". The file ChessAnalyzerProSetup.exe is saved to your Downloads folder.

    ⬇ Download Chess Analyzer Pro for WindowsThe installer will be available for download here soon.

  3. Install the program

    Double-click the downloaded file and follow the on-screen steps. The Stockfish chess engine is installed automatically with the program – nothing else to download or set up. Windows may warn about an unrecognised app; if so, click "More info" and then "Run anyway".

  4. Download a game from Chess.com

    Go to Chess.com and open a finished game (for example from your game archive). A green "Download game (PGN)" button appears in the bottom corner of the page. Clicking it saves the game as a PGN file in your Downloads folder. Games still in progress cannot be downloaded.

  5. Open the game in the program

    Start Chess Analyzer Pro, click "Choose a game from your computer" and pick the PGN file you downloaded. You can also drag the file into the program window.

  6. Analyse and read the results

    Analysis starts by itself and usually takes under a minute. Step through the moves with the ◀ ▶ buttons or the arrow keys, and you will see:

    • A coloured icon next to every move – in the move list and on the board.
    • A short explanation of the move and, after a mistake, the better move.
    • Three arrows on the board: green (best), blue (second) and orange (third).
    • The evaluation bar beside the board, showing who is ahead.
    • Each player's accuracy percentage and the game summary.

Tip: the "Analysis depth" menu lets you choose fast, normal or deep analysis. Deep analysis is more precise but takes longer.

Legend

  • !!BrilliantAn exceptional move, usually a piece sacrifice the engine approves.
  • !Great moveThe only move that holds the position or keeps the advantage.
  • ★Best moveExactly what the engine recommends.
  • ✓Good moveA sound move, even if not the most precise.
  • ?!InaccuracyA slightly weaker move.
  • ?MistakeA move that hurts the player's position.
  • ??BlunderA move that seriously damages the position.
  • ✕MissA missed chance after the opponent's error.
